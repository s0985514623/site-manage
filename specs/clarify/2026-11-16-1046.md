# Clarify Session 2026-11-16 10:46

## Idea

1. 管理現有的網站客戶，提醒到期日、自動建立報價單，由用戶手動寄出給客戶（未來可能改成 LINE 確認後自動發送 mail）
2. 可以建立新的專案並連結至 Google Calendar 進行專案管理
3. 除了網頁版管理後台，也能透過 LINE 進行查詢/新增/管理
4. 希望盡可能自動化、減少人工處理時的遺漏，請依你查看提出其他建議

## Q&A

- Q: 「LINE 確認後自動寄出」已實作，如何處理？ → A: 設定頁加開關，手動寄 / LINE 確認後自動寄 可切換（預設手動）
- Q: 「專案」指什麼？ → A: 可區分成新網站製作案、客製化外掛、BUG 排除等分類
- Q: 不同類別流程是否不同？ → A: 所有類別共用一組狀態（待開始→進行中→待驗收→已完成），類別僅作標籤/篩選；只有「新網站」完成時自動轉維運（建立網站 + 服務項目）
- Q: 專案如何連結 Google Calendar？ → A: 單向寫入，專案里程碑與截止日寫入 Google Calendar，沿用現有 gcal.ts
- Q: LINE 第一版範圍？ → A: 查詢 + 快速新增（選單按鈕），修改刪除留在網頁後台
- Q: 使用者人數？ → A: 只有用戶本人（沿用單一 LINE 管理者 + Email 白名單）
- Q: 專案可否產生報價？ → A: 可在專案頁產生報價草稿，沿用現有報價/PDF 流程
- Q: 防遺漏建議採用哪些？ → A: 全選：報價寄出 N 天未回覆 LINE 提醒、收款追蹤、排程停擺告警、每週一 LINE 週報
- Q: 專案與網站如何關聯？ → A: 專案可以不綁網站，報價單的網站欄位改為可空
- Q: 里程碑結構？ → A: 每個專案可有多個自訂里程碑（名稱 + 日期），每個都寫入 Google Calendar
- Q: 新網站完成轉維運如何建立服務項目？ → A: 完成時跳出表單，勾選要建立的服務項目並填到期日與售價
- Q: 手動寄的意義？ → A: 自動寄信開關關閉時，在後台按「寄出」由系統寄 email，並自動記錄寄出日

## 已採預設（用戶已確認，2026-11-16 全部接受）

- 未回覆追蹤：寄出滿 7 天提醒，之後每 7 天重複；天數可在設定頁調整；過有效期不自動改狀態，只在提醒中標示
- 收款：已寄出 / 已同意皆可登記（登記即視為同意）；必填收款日與實收金額，匯款證明選填；收款不自動推進到期日
- 未收款提醒：續約報價自錨點到期日前 7 天起、專案報價自同意後 14 天起，每 3 天重複
- 寄送模式：切到手動後舊 LINE 確認按鈕拒絕寄信；手動模式產生續約草稿時推 LINE 純通知；切到 LINE 模式需已設定 LINE 管理者
- 專案欄位：必填名稱、客戶、類別；選填網站、開始日、截止日、說明、預估金額；有報價單時禁止刪除
- 專案狀態四者可任意切換；轉維運表單只在新網站第一次完成時出現；未綁網站時一併建立網站
- 專案報價：任何狀態可產生、可多張、項目手動輸入可從方案範本帶入；未綁網站時以專案名稱取代網站名稱
- 日曆：里程碑 / 專案完成後事件保留；同步失敗不擋存檔，每日對帳補上
- LINE：Rich Menu + Quick Reply；查詢三類（近期到期、待處理報價、進行中專案）各最多 5 筆 + 後台連結；快速新增只限專案
- 週報週一 09:00，無待辦也推「本週無待辦」；排程容許時間 每日 26h / 每週 8 天 / 每小時 3h，同日只告警一次

## Q&A（續）

- Q: 專案類別固定或自訂？ → A: 固定四類：新網站、客製化外掛、BUG 排除、其他
- Q: 專案事件寫入哪個日曆？ → A: 另開「專案管理」Google 日曆，與「網站到期管理」分開
- Q: LINE 快速新增專案的輸入方式？ → A: 按鈕逐步選（選客戶 → 選類別 → 輸入名稱 → 選日期）
- Q: 整台停擺如何告警？ → A: 用戶另一台 PHP 主機做心跳檢查：VPS 各排程成功後 ping PHP 心跳端點；PHP cron 每 15 分鐘檢查，心跳逾時（依排程頻率門檻）或 VPS /api/health 失敗時，同時發 LINE push + Email。PHP 端為獨立小腳本

## Quality Gate 期間補強的推導預設（用戶已確認）

- /api/health 不需登入，只回 200 / 503，不含內部細節
- 原「排程檢查排程健康」由外部心跳取代，該 .feature 已移除
- LINE 選客戶列最近有異動的 12 位啟用客戶 + 關鍵字搜尋；日期用 LINE 日期選擇器可略過；30 分鐘無回應自動放棄
- 參數驗證：名稱不可空白、截止日不早於開始日、金額 ≥ 0、實收金額 > 0、收款日不晚於今天、報價至少一項；重複寄出 / 重複登記收款會被擋下

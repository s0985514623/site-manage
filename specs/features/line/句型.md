# line 句型模型

## 實體概述

- **性質**: Aggregate（LINE 對話進度 line_conversations）+ Gateway（LINE reply）
- **攜帶狀態**: step（choose_client / choose_category / input_name / choose_due_date）、client、category、name、updated_at
- **Invariant 清單**:
  - 只處理管理者帳號；簽章不正確回 401
  - 進度閒置 > 30 分鐘視為過期；取消 / 完成 / 過期即刪除
  - 查詢與問答一律 reply，不計推播額度
  - 「近期到期」= 30 天內到期（含已逾期）且狀態 active 的服務項目

## 操作清單

| 操作 | 行為分類 | When Data Table 欄位 | Then Data Table 欄位 | Violation Types |
|------|---------|---------------------|---------------------|-----------------|

## 測試分析

### 透過 LINE 查詢資訊
**等價類**: 三種查詢；管理者 / 非管理者；簽章正確 / 錯誤
**邊界值**: 5 筆上限（6 筆時顯示 5 筆 + 還有 1 筆）；30 天到期窗口（14 天內列出、7 個月後不列）
**狀態轉移**: 不適用（查詢）　**組合**: 待處理報價三類同時存在 + 已收款不列
**錯誤推測**: 已完成專案不應出現在進行中；回覆誤用 push 會耗額度

### 透過 LINE 快速新增專案
**等價類**: 每個 step 的合法輸入 / 不符輸入；日期 選擇 / 略過；取消
**邊界值**: 閒置 30 分鐘（有效）vs 31 分鐘（過期）；客戶 12 位上限
**狀態轉移**: choose_client → choose_category → input_name → choose_due_date → 建立並刪除進度
**組合**: 關鍵字搜尋 × 停用客戶不列
**錯誤推測**: 非管理者、空白名稱、選類別時打字

# ops 句型模型

## 實體概述

- **性質**: Gateway 為主（LINE、Email、心跳）+ 通知紀錄 Aggregate（週報去重）
- **攜帶狀態**: notifications(kind = weekly_report, sent_on)
- **Invariant 清單**:
  - 「本週」= 今天（週一）起 7 天內（含今天至下週日）
  - 週報同日只推一次；無待辦也推
  - /api/health 不需登入，只回 `{ status }`，DB 不通回 503

## 操作清單

| 操作 | 行為分類 | When Data Table 欄位 | Then Data Table 欄位 | Violation Types |

| 排程推送每週週報 | Diagnostic | — | kind、contains / job | — |
| 外部監控查詢系統健康 | Query | — | status、field | — |

## 測試分析

### 排程推送每週週報
**等價類**: 有待辦 / 無待辦；額度足 / 不足
**邊界值**: 本週窗口（11-20、11-21、11-18 列入；11-24 不列入）
**狀態轉移**: 不適用　**組合**: 四類待辦同時存在 → 1 則　**錯誤推測**: 同日重跑重複推送

### 外部監控查詢系統健康
**等價類**: DB 正常 / DB 斷線　**邊界值**: 不適用　**狀態轉移**: 不適用
**組合**: 不適用　**錯誤推測**: 回應洩漏版本或錯誤堆疊

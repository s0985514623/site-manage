# project 句型模型

## 實體概述

- **性質**: Aggregate（專案，含子實體里程碑）+ Gateway（Google Calendar）
- **攜帶狀態**: category、status、start_date、due_date、site_id?、handover_completed_at、gcal_event_id；里程碑 name、due_on、completed_at、gcal_event_id
- **Invariant 清單**:
  - category ∈ {new_site, custom_plugin, bug_fix, other}；status ∈ {not_started, in_progress, in_review, completed}，可任意切換
  - name 不可空白；due_date ≥ start_date；estimated_amount ≥ 0；site 必須屬於同一客戶；客戶必須啟用
  - 有報價單不可刪除
  - 轉維運：僅 new_site + completed + handover_completed_at 為空；成功後寫入 handover_completed_at
  - 日曆同步失敗不影響操作成功

## 測試分析

### 建立專案
**等價類**: 4 類別 + 非法類別；必填缺漏 ×3；客戶 啟用 / 停用 / 不存在；有 / 無網站
**邊界值**: 名稱只有空白；截止日 = 開始日 − 1；金額 −1
**狀態轉移**: 無 → not_started　**組合**: 網站 × 其他客戶　**錯誤推測**: 日曆斷線
（Examples 規劃 13 行，見 Feature；每個前置至少 1 行拒絕路徑）

### 編輯專案 / 刪除專案
**等價類**: 空名稱、日期顛倒、網站錯客戶、不存在　**邊界值**: 截止日清空
**狀態轉移**: 有報價單 → 刪除被拒；無報價單 → 刪除 + 里程碑 + 事件一併移除　**組合**: 不適用　**錯誤推測**: 刪除後殘留日曆事件

### 更新專案狀態
**等價類**: 合法 4 狀態 + 非法　**邊界值**: 第一次 vs 第二次完成
**狀態轉移**: 前進、退回、跳級、從 completed 退回　**組合**: 類別 × completed　**錯誤推測**: 已轉維運再完成

### 送出轉維運表單
**等價類**: 非新網站 / 未完成 / 已轉維運；類型非法、缺識別名稱、缺到期日、缺售價、售價 −1；零項目
**邊界值**: 售價 −1 / 0 以上　**狀態轉移**: 未綁網站 → 新建 live 網站；已綁 building 網站 → live
**組合**: 兩項服務同時建立　**錯誤推測**: 重複送出（以 handover_completed_at 擋）

### 管理專案里程碑
**等價類**: 空名稱、空白名稱、缺日期、專案不存在　**邊界值**: 不適用
**狀態轉移**: 新增 → 事件建立；修改 → 事件更新；刪除 → 事件移除；完成 → 事件保留　**組合**: 不適用　**錯誤推測**: 日曆斷線

### 查詢專案列表
**等價類**: 依類別、依狀態、不篩選　**邊界值**: 無截止日排最後；截止日 < 今天且未完成 → 逾期；已完成不算逾期
**狀態轉移**: 不適用　**組合**: 類別 + 狀態同時篩選（未單獨列行，由各自篩選覆蓋）　**錯誤推測**: 已完成但截止日已過不應標逾期

### 從專案產生報價草稿
**等價類**: 項目 空說明 / 數量 0 / 單價負數 / 零項目；專案 有網站 / 無網站；手動 / 從範本
**邊界值**: 數量 0、單價 −1　**狀態轉移**: 不同專案狀態皆可；已有報價單可再開
**組合**: 範本帶入 × 調整單價　**錯誤推測**: 手動模式產生專案報價不應推 LINE

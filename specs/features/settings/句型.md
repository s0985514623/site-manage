# settings 句型模型

## 實體概述

- **性質**: Aggregate（單列設定）
- **攜帶狀態**: auto_send_enabled（預設 false）
- **Invariant 清單**: auto_send_enabled = true 時 LINE 管理者必須已設定

## 操作清單

| 操作 | 行為分類 | When Data Table 欄位 | Then Data Table 欄位 | Violation Types |
|------|---------|---------------------|---------------------|-----------------|
| 切換報價寄送模式 | Mutation | mode | auto_send_enabled | INVALID_ARGUMENT、LINE_ADMIN_NOT_CONFIGURED |
| 查詢系統設定 | Query | — | auto_send_enabled | — |

## 句型清單

| # | 類別 | 句型 | Handler | 參數槽 |
|---|------|------|---------|-------|
| G1 | Given | → 系統抽象 C1 / C2 / C3 / C6 | aggregate-given | — |
| G2 | Given | `Given 系統尚未儲存任何設定` | aggregate-given | — |
| W1 | When | `When 管理者切換報價寄送模式：` | command | mode |
| W2 | When | `When 管理者查詢系統設定` | query | — |
| T1 | Then | → 系統抽象 C9 / C10 / C15 | success-failure / aggregate-then | — |
| T2 | Then | `Then 系統設定應為：` | aggregate-then | auto_send_enabled |

## 測試分析

### 切換報價寄送模式

**等價類劃分**: mode ∈ {手動寄, LINE確認後自動寄, 其他字串, 空}
**邊界值分析**: 不適用（列舉值）
**狀態轉移**: false → true、true → false；LINE 管理者未設定時 false → true 被拒
**組合覆蓋**: 切換為手動寄 × 存在待確認報價單
**錯誤推測**: 空字串、看似合法但不在列舉內的字

**Examples 規劃**:

| # | 驗證目標 | 額外前置狀態 | 輸入資料摘要 | 預期結果 | 分析維度 |
|---|---------|-------------|-------------|---------|---------|
| 1 | 空 mode | 設定（LINE 已設） | mode=空 | 失敗(INVALID_ARGUMENT) | 等價類 |
| 2 | 非列舉值 | 設定（LINE 已設） | mode=自動寄給客戶 | 失敗(INVALID_ARGUMENT) | 錯誤推測 |
| 3 | LINE 未設定 | 設定（LINE 未設） | mode=LINE確認後自動寄 | 失敗(LINE_ADMIN_NOT_CONFIGURED) | 狀態轉移 |
| 4 | 預設值 | 無設定列 | 查詢 | false | 邊界值 |
| 5 | 開啟 | 設定 false | LINE確認後自動寄 | true | 狀態轉移 |
| 6 | 關閉 | 設定 true | 手動寄 | false | 狀態轉移 |
| 7 | 待確認報價不受影響 | 設定 true + 待確認報價 | 手動寄 | 報價仍 pending_approval | 組合覆蓋 |

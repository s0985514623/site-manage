# 系統抽象

> Boundary：`web-backend`（偵測到 `specs/entity/erm.dbml`）。
> 本系統的「API Layer」由 Next.js Server Actions 與 `/api/*` Route Handlers 組成；
> 測試時兩者皆視為 Operation Invocation，DB 為 States Prepare / States Verify 的對象。
> 外部服務（LINE Messaging API、Resend、Google Calendar、外部監控心跳端點）在測試中以 fake gateway 取代，
> 其「應收到什麼」以 Gateway Then 句型驗證。

## 實體清單

| 實體 | 性質 | 攜帶狀態摘要 | 對應 features subfolder |
|------|------|-------------|------------------------|
| 設定（settings） | Aggregate（單列） | auto_send_enabled、quote_followup_days、gcal_project_calendar_id | settings/ |
| 報價單（quotes） | Aggregate | status、sent_at、accepted_at、paid_on、paid_amount、site_id?、project_id? | quote/、payment/ |
| 專案（projects） | Aggregate | category、status、日期、handover_completed_at、gcal_event_id | project/ |
| 里程碑（project_milestones） | Aggregate 子實體 | name、due_on、completed_at、gcal_event_id | project/ |
| LINE 對話（line_conversations） | Aggregate | step、data、expires_at | line/ |
| 通知紀錄（notifications） | Aggregate（去重） | kind、quote_id、channel、sent_on | quote/、payment/、ops/ |
| LINE 推播 / 回覆 | Gateway | 送出的訊息 | 跨 domain |
| Email（Resend） | Gateway | 寄出的信件 | quote/、ops/ |

## 行為分類與句型骨架

### Creation / Mutation
- When：`When 管理者<操作>：`（接 Data Table）
- Then 成功：`Then 操作成功` + States Verify（`Then <實體> "<key>" 應為：`）
- Then 失敗：`Then 操作失敗，violation_type 為 "<violation>"`

### Query
- When：`When 管理者查詢<對象>：`
- Then：`Then 查詢結果應為：`（依序比對）

### Diagnostic（排程通知）
- When：`When 排程執行「<job>」`
- Then：Gateway 驗證（`Then LINE 應推播給管理者以下訊息：`、`Then 不應推播任何 LINE 訊息`、`Then 心跳端點應收到以下 ping：`）

## 共用契約

### Postcondition 模式
- 寫入專案 / 里程碑日期 → 「專案管理」日曆事件同步；日曆失敗不影響操作成功
- 排程成功 → ping 心跳端點；ping 失敗不影響排程結果
- 通知 → 同一對象同一天只發一次；多筆彙總成一則 LINE；LINE 額度不足改寄 Email

### Violation 模式
| violation_type | 意義 | 對應 HTTP |
|----------------|------|-----------|
| INVALID_ARGUMENT | 參數缺少、空白、格式或範圍錯誤 | 400 |
| INVALID_DATE_RANGE | 截止日早於開始日 | 400 |
| NOT_FOUND | 指定資源不存在 | 404 |
| CLIENT_INACTIVE | 客戶為停用 | 422 |
| SITE_CLIENT_MISMATCH | 網站不屬於該客戶 | 422 |
| INVALID_QUOTE_STATUS | 報價單狀態不允許此操作 | 422 |
| QUOTE_ALREADY_SENT | 報價單已寄出 | 422 |
| NO_RECIPIENT | 客戶沒有報價收件人 | 422 |
| MAIL_NOT_CONFIGURED | 寄信服務未設定 | 422 |
| MAIL_SEND_FAILED | 寄信服務回報失敗 | 502 |
| LINE_ADMIN_NOT_CONFIGURED | 未設定 LINE 管理者 | 422 |
| ALREADY_PAID | 已登記收款 | 422 |
| PROJECT_HAS_QUOTES | 專案已有報價單 | 422 |
| HANDOVER_NOT_ALLOWED | 非新網站、未完成或已轉維運 | 422 |

## 變異點索引

| 實體 | 特有行為 | 需要的專屬句型類別 |
|------|---------|------------------|
| 設定 | 寄送模式切換的前置條件 | When |
| 報價單 | 寄送模式分流、追蹤節奏、收款 | When、Given（Email 失敗）、Then（續約狀態） |
| 專案 | 轉維運建立網站與服務項目 | When、Then（網站 / 服務項目） |

| LINE | 多步問答、reply 不耗額度 | Given（對話進度）、When（LINE 事件）、Then（LINE 回覆） |
| 健康檢查 | 無登入、只回 HTTP 狀態 | When、Then（HTTP 狀態碼） |
